# VONO — רשימת צעדים לפני מעבר מגרסת הבדיקות לגרסה הראשית

עודכן: 18.10.2026

## קודם כל, הסבר קצר

- **TEST** = סביבת הבדיקות. שם נמצא כל מה שבנינו בשבועות האחרונים. הנגנים בסניפים (Lenovo, מחשב הפיתוח, 092) מחוברים אליה.
- **PROD** = המערכת הראשית והאמיתית. עדיין רצה הגרסה הישנה.
- **main** = הגרסה הראשית ב-GitHub. ברגע שמכניסים אליה שינוי, PROD מתעדכן לבד מיד.
- **"מיזוג" (merge)** = העברת כל העבודה מ-TEST לגרסה הראשית.

## שלב 0 — לשמור את העבודה ב-GitHub (אפשר עכשיו, לא פוגע בכלום)

במחשב הזה, בתיקיית הפרויקט, להריץ פקודה אחת:

```
git push -u origin playback/p0-gate1-url-transition
```

- זה שומר את כל העבודה ב-GitHub בענף נפרד.
- **PROD לא משתנה.**
- אחרי זה אפשר לעבוד מכל מחשב.

**במחשב אחר:**
1. `git clone https://github.com/djdotansharon-creator/syncbiz-app.git`
2. `git checkout playback/p0-gate1-url-transition`
3. `npm install`
4. להעתיק את קבצי ההגדרות עם המפתחות (`.env.local` וכו') בדרך מאובטחת, למשל דיסק-און-קי. **אף פעם לא דרך GitHub או צ'אט.**

**הבן שלך:** הוא עובד על גרסה ישנה יותר. שימשוך את הענף הזה, ואחר כך נשלב את העיצוב שלו בזהירות.
